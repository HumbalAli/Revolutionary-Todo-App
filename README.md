# Revolutionary Todo
> *Elite productivity through high-fidelity intelligence.*

Revolutionary Todo is a premium, high-fidelity task management system designed for maximum impact. By combining an obsidian-dark aesthetic with deep AI integration, it transforms standard task logic into a mission-critical command center.

## 🌌 Vanta Vision
Built with the **Vanta Vision** design language, the app features deep obsidian backgrounds, cybernetic glows, and premium glassmorphism. It is designed to be minimal, powerful, and easy on the eyes during long sessions.

## 🚀 Key Features
- **Integrated AI Side-Pane**: A mission-control sidebar where the Quantum Assistant processes your natural language commands.
- **Protocol Stream**: Your tasks are managed as interactive protocols with glowing status indicators and high-end animations.
- **System Command Bar**: A futuristic input area for rapid task initialization and AI interaction.
- **Luxury Aesthetic**: A blend of deep blacks, royal blues, and neon accents for an elite workspace feel.

## 🛠️ Tech Stack
- **Frontend**: Next.js 15, Tailwind CSS, TypeScript (Outfit & Space Grotesk typography).
- **Backend**: FastAPI, SQLAlchemy, PostgreSQL.
- **AI Core**: OpenAI/Groq Task Management Agent.
- **Infrastructure**: Docker, Minikube, Helm.

## 📦 Getting Started

### Local Dev Setup
```bash
# Frontend
cd frontend
npm run dev

# Backend
cd backend
python main.py
```

### Protocol Deployment (K8s)
Use the provided binaries in the root:
1. `.\minikube start`
2. `.\helm install revolutionary ./charts`
3. `.\minikube service todo-chatbot-frontend --url`
